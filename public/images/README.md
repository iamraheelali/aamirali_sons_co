# Image Assets

Product visuals are rendered as CSS/SVG (MarahilBottle / JewelryVisual) by
default, so the storefront never shows broken images.

To replace a visual with real photography, drop the file at the matching path:

- Fahl hero (two brothers): `public/images/fahl/hero-brothers.jpg`
- Fahl chapters: `public/images/fahl/{bad,ishraq,zuhr,athar,wasl,layl}.jpg`
- Fahl discovery: `public/images/fahl/discovery.jpg`
- Aniqa chapters: `public/images/aniqa/{bad,ishraq,zuhr,athar,wasl,layl}.jpg`
- Aniqa discovery: `public/images/aniqa/discovery.jpg`
- Jewelry: `public/images/jewelry/`

Do not fabricate personal likenesses. Until an approved photograph of the
brothers is supplied, the hero renders the designed luxury bottle composition.
